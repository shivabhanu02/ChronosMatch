
# ChronosMatch: Zero-Copy High-Frequency Trading Engine

## Project Overview

ChronosMatch is a Python-based market order simulation project designed to explore low-latency order processing, memory-mapped communication, and matching engine design.

## Objectives

- Simulate market orders.
- Explore memory-mapped inter-process communication.
- Implement price-time priority matching.
- Measure order-processing latency.
- Test correctness and document performance.

## Technologies

- Python
- Git and GitHub
- mmap and struct
- asyncio
- Cython
- SQLite
